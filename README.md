# 📝 Text Summarizer

An end-to-end NLP project that summarizes long text using the DistilBART model, built with FastAPI and deployed on Hugging Face Spaces.

## 🚀 Demo
[Live Demo on Hugging Face](https://huggingface.co/spaces/iruventyuma28/text-summarizer)

## 🛠️ Tech Stack
- **Model**: DistilBART (sshleifer/distilbart-cnn-12-6)
- **Framework**: FastAPI
- **ML Library**: Hugging Face Transformers
- **Deployment**: Hugging Face Spaces (Docker)



## 🧠 How It Works
1. User inputs long text
2. Text is tokenized using DistilBART tokenizer
3. Model generates a concise summary
4. Summary is displayed in the UI
